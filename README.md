# IMT Production dashboard (demo)

Factory dashboard demo for Inland Machine Tools, built by KaptainX. All data is sample data.

- `index.html`: the finished page. Open it in a browser, or host it as-is.
- `src/template.html`: the source to edit (HTML, CSS, JS and sample data in one file).
- `fonts/`: SF Pro Display, trimmed to the characters the page uses.
- `build.py`: puts the fonts into the page. Run `python3 build.py` after every edit.

Screens: Today, Jobs, Vendors, Money, Quality, plus the WhatsApp report preview.
The page works on phones and desktops. On a phone it opens on a given screen with a link like `index.html#jobs`.

Note: SF Pro is licensed by Apple. Keep this repo private, and switch to a free font before using it on a live client system.
